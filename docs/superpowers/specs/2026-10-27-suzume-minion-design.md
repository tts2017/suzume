# タビスズメ リアル化プラグイン 設計書

- 日付: 2026-10-27
- 状態: レビュー待ち
- 対象: FFXIV ミニオン「タビスズメ」(Companion #247 / モデル `chara/monster/m8217`)

## 1. 目的

自分が呼び出したミニオン「タビスズメ」の見た目の動きを、実際のスズメ(*Passer montanus*)の行動に近づける。
あわせて、行動に連動した鳴き声 4 種類を再生する。

### 成功条件

- 地上移動が「滑るような飛行」ではなく、両足ホップの連続 + 停止の繰り返しに見える
- 停止中に、キョロキョロ(素早い向き変え)・ついばみが自然な間隔で起こる
- プレイヤーとの距離が開いたときだけ飛び、着地後はホップに戻る
- 4 種類の鳴き声が行動に応じて鳴り、うるさすぎない(音量・頻度を設定で調整できる)
- プラグインを無効化すれば、ゲーム本来の挙動に完全に戻る

### 範囲外 (v1)

- ボーン単位の姿勢操作(首かしげ、尾振り、翼の動き) → v2
- 他プレイヤーのタビスズメの制御
- 他プレイヤーへの同期(すべて自分のクライアント上の見た目だけ)
- 録音素材の利用(v1 は合成音のみ。ただし差し替え可能な構造にする)

### 注意

クライアントを改変するプラグインはゲームの利用規約に反する。自己責任での個人利用を前提とする。

## 2. 調査済みの前提

- Companion #247 の行動タイプは「自律」(Behavior 2)
- 骨格 (`skl_m8217b0001.sklb`) のボーン 15 本:
  `n_root n_hara j_kosi j_sebo j_kubi j_tail j_mouth j_mouth_up j_ude_a_l/r j_ude_b_l/r j_asi_a_l/r j_asi_b_l/r`
- 既存アニメーション (`resident/monster.pap`) は 3 本のみ:
  - `cbnm_id0` 待機
  - `cbnm_idact1` 待機アクション
  - `cbnm_02f_lp0` 飛行ループ
- ゲーム本来の挙動では、移動中は常に飛行ループ。ホップ用アニメーションは存在しない
  → ホップは「待機アニメーションを再生したまま、描画位置を放物線で動かす」ことで表現する

## 3. 全体構成

```
G:\ff14\suzume
├─ src/
│  ├─ Suzume.Core/        ゲーム非依存のロジック(テスト対象)
│  └─ Suzume/             Dalamud プラグイン本体
├─ tests/
│  └─ Suzume.Core.Tests/  xUnit テスト
├─ tools/
│  └─ chirps.py           鳴き声合成スクリプト(numpy)
└─ assets/sounds/         合成済み WAV(プラグインに埋め込み)
```

### 3.1 データの流れ (毎フレーム)

```
ゲーム(本来の追従ロジック)
   │ ミニオンの論理位置 Pg、プレイヤー位置・速度・騎乗状態
   ▼
MinionTracker ──► SparrowBrain.Tick(dt, 入力) ──► 出力 SparrowPose
                                                   ├─ 表示位置 Pv、向き yaw、前傾 pitch
                                                   ├─ アニメ指定 (Idle / IdleAction / Fly)
                                                   └─ 音イベント (種類, 位置)
                         ┌─────────────────────────┤
                         ▼                         ▼
                 PoseApplier                 ChirpPlayer
             (描画 Transform 上書き、        (NAudio 再生、距離減衰)
              アニメ強制切替)
```

ゲーム側の追従ロジック(論理位置 Pg)には手を加えない。
プラグインは「描画上の位置 Pv」を別に持ち、Pv が Pg をホップや飛行で追いかける。

## 4. コンポーネント

### 4.1 Suzume.Core (ゲーム非依存)

ゲーム API を参照しない純粋な C#。乱数は注入式にし、シード固定でテストできるようにする。

- `SparrowInput`: dt、論理位置 Pg、プレイヤー位置・速度、騎乗中か、地面高さ
- `SparrowPose`: 表示位置 Pv、yaw、pitch、アニメ指定、音イベントのリスト
- `SparrowBrain`: 状態機械。`Tick(SparrowInput) → SparrowPose`
- `SparrowParams`: 全パラメータ(下表)。設定画面から一部変更可
- `ChirpScheduler`: 状態ごとの鳴き声選択と、最小間隔・頻度倍率の管理

### 4.2 行動状態機械

| 状態 | 内容 | 主な遷移 |
|---|---|---|
| Idle | 待機。0.5〜1.0 秒ごとに Scan を挟む | Pg との距離 > 0.4y → Hop / 距離 > 飛行閾値 → TakeOff / 一定確率 → Forage, Preen |
| Scan | yaw を 20〜70° 瞬時に変更(補間なし、1 フレームで完了)。独立した状態にはせず、Idle 中に 0.5〜1.0 秒ごとに起こる瞬間動作として実装する | Idle のまま |
| Hop | 両足ホップ 2〜6 回連続 → 停止 | 連続終了 → Idle / 距離 > 飛行閾値 → TakeOff |
| Forage | 前傾ついばみ 2〜5 回 (各 0.15 秒、pitch 35° 前後) | → Idle |
| Preen | 小刻みな pitch / yaw の揺れ 1〜2 秒(v2 でボーン操作に置換) | → Idle |
| TakeOff | 飛翔声を鳴らし上昇 | → Fly |
| Fly | 波状飛行: 羽ばたき区間で上昇、滑空区間で下降。Pg 付近へ向かう | 目標まで 1y 未満 → Land |
| Land | 着地。着地直後に小さな前傾(尾を上げる動きの代用) | → Idle |
| Alarm | プレイヤーが高速で 2y 以内に接近 → 警戒声 + 反対方向へ 1〜3 回ホップ or 短距離飛行 | → Idle |

### 4.3 ホップの物理

- 1 回のホップ: 時間 0.12 秒、水平距離 0.15〜0.3y、最高点 0.06〜0.1y の放物線
- ホップ中の yaw は固定。向き変更はホップとホップの間に瞬時に行う
- 連続ホップの間隔: 0.05〜0.15 秒
- 地面高さは Pg の Y を使う(ゲームが地形に合わせて計算済みの値)

### 4.4 飛行

- 飛行閾値の既定値: Pg との距離 6y、またはプレイヤーが騎乗中・全力疾走中
- 波状飛行: 羽ばたき 0.3 秒(上昇) + 滑空 0.2 秒(下降)を繰り返す
- 飛行中はアニメーションを `cbnm_02f_lp0`、それ以外は `cbnm_id0` に固定
- Pv と Pg の差が 30y を超えたら(テレポート、エリア移動など)即座に Pv = Pg にリセット

### 4.5 鳴き声 (tools/chirps.py)

numpy のみで合成。44.1kHz / 16bit / モノラル WAV。各種類 3 バリエーション(ピッチ・長さを微妙に変える)。

| 種類 | 聞こえ方 | 合成方法 | 使う場面 |
|---|---|---|---|
| Contact | 「チュン」 | 0.08〜0.12 秒の単音。基本周波数 3.5〜4.5kHz から下降する FM、2〜3 倍音、立ち上がり速く減衰短い | Idle / Hop 中にときどき |
| Song | 「チュンチュン」 | Contact に似た音を 2〜4 回、間隔 0.12〜0.2 秒で連続、音ごとにピッチ揺らぎ | Idle 中の長めの停止時 |
| Alarm | 「ジュクジュク」 | 帯域ノイズ(3〜7kHz)を約 12Hz でパルス変調、0.4〜0.6 秒 | Alarm |
| Flight | 「チュリリ」 | 上昇 FM の短音を 15〜20Hz で転がすトリル、0.25〜0.35 秒 | TakeOff |

- 最小間隔(既定 1.5 秒)と頻度倍率で鳴きすぎを防ぐ
- WAV はプラグインに埋め込みリソースとして同梱。ファイル名規約を固定し、将来録音素材に差し替えられるようにする

### 4.6 Suzume (Dalamud プラグイン)

- `MinionTracker`: ローカルプレイヤーのコンパニオンオブジェクトを取得し、Companion ID が 247 のときだけ有効。消えたら状態をリセット
- `PoseApplier`: 毎フレーム、ミニオンの描画オブジェクトの位置・回転を SparrowPose で上書き。ベースアニメーションを指定のものに強制。無効化時は上書きをやめ、アニメ指定を解除
- `ChirpPlayer`: NAudio で再生。音量 = 設定音量 × プレイヤーとミニオンの距離による減衰(5y 以内は等倍、30y で無音)。同時再生は最大 2
- `ConfigWindow`: 有効/無効、音量、鳴き声頻度、飛行閾値、デバッグ表示(現在の状態名、Pv と Pg)
- コマンド: `/suzume` で設定画面

## 5. 技術リスクと検証順

1. **描画 Transform の上書きがゲームに打ち消されないか**(最大のリスク)
   最初にスパイクとして、ミニオンを上下に跳ねさせるだけの最小プラグインで確認する。
   打ち消される場合は、上書きのタイミング(フック位置)を変える。
2. **ベースアニメーションの強制切替**
   飛行ループを止めて待機アニメに固定できるか、スパイクで合わせて確認する。
3. NAudio がプラグイン環境で問題なく再生できるか。

1・2 が成立しない場合は、設計を見直してから先に進む。

## 6. エラー処理

- ミニオン未召喚、別ミニオン、ロード画面中、カットシーン中、GPose 中 → 何もしない(上書きもしない)
- 例外は Framework.Update 内で捕捉してログに出し、そのフレームは上書きを諦める(ゲームを落とさない)
- 連続して例外が出た場合は自動で無効化し、チャットに通知する

## 7. テスト

- `Suzume.Core.Tests`(xUnit)
  - シード固定で状態遷移が決定的であること
  - ホップの放物線(最高点・着地点・所要時間)
  - 距離閾値で Fly に入り、着地後 Idle に戻ること
  - 30y 超でのリセット
  - 鳴き声の最小間隔が守られること
- 鳴き声: 生成した WAV の長さ・ピーク周波数を Python で検証し、スペクトログラム画像を出力して確認
- 実機: ユーザーがゲーム内で目視・聴覚で確認(Claude からは確認できない)
